Create a QR code from text or a link

Encode a website address or a short piece of text in a QR code that you can save as a PNG. No account is required. The result includes a white border so scanners can distinguish the code from its surroundings.

How to use this tool

  1. Enter your text or a complete URL, including https:// for a website.
  2. Click Generate QR code to see the preview.
  3. Download the PNG and test it with a QR scanner before printing or sharing.

Is the QR code stored or time limited?

Your text is processed by the server without being stored, and the PNG is downloaded directly. The code itself has no expiry date, although a linked website can change or become unavailable. Input is limited to 2000 UTF-8 bytes; accented letters and emoji may use more than one byte. Keep the white border when placing the code in a design.
