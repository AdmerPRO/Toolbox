Privacy policy

Last updated: 1 October 2026. This page explains how Tool Box handles files and related data.

Files and processing

When you use a converter, your original file is uploaded to this server to produce the requested image or audio file. Successful jobs store both the original and the result. YouTube tools send your submitted link to YouTube through yt-dlp and store the downloaded result on this server. Failed jobs use temporary working files that are normally removed when processing ends. An abrupt shutdown can leave temporary files on disk until the operator cleans them up.

Seven-day availability and ZIP archives

Stored files remain in active storage for 7 days. Download links stop working after that period. An automated task runs at server startup and once per hour to move expired files into ZIP archives. If the server is offline or archiving fails, files remain on disk until a successful retry.

Files are grouped by UTC date in folders named DDMMYYYY. For example, 01102026 means 01.10.2026. Files from the same day share a date folder; multiple ZIP archives can be created for that day.

Archiving is not deletion. ZIP archives contain uploaded originals and generated results. Each archive is automatically deleted 30 days after it is created, rather than 30 days after the original upload. Deletion runs at startup and hourly; if the server is offline or deletion fails, the archive remains until a successful retry. This typically means about 37 days of total retention, although downtime or processing failures can extend it. The server operator can access stored files and archives. Archives are not offered for download through the website.

Download links

No account is required. Generated results have random download identifiers, but anyone with the full download link can retrieve the result during its seven-day availability. Keep your links private. Original uploads are not exposed through the download endpoint. Avoid uploading sensitive or confidential material.

Cookies and request information

The home page uses a cookie called popup_seen_v2 for one day to remember that you have closed the welcome message. The application does not include advertising or analytics scripts. Server logging can record request details and errors, including requested file identifiers. Hosting infrastructure may also keep connection logs; their retention depends on the operator's configuration and is separate from the file policy above.

External services

YouTube tools contact YouTube to retrieve video information and media. Video thumbnails load from external image hosts, which receive your connection information when your browser requests them. Image conversion, resizing, uploaded MP4 audio extraction, and video muting run on this server.

Questions and deletion requests

Contact the operator of the Tool Box server you are using for privacy questions or a request to delete stored data. Provide your download identifier privately so the operator can locate related originals, results, and archives. Do not post private files or download links in public GitHub issues.
