Image format converter

Switch between PNG, JPG, JPEG, GIF, WebP, ICO, BMP, and TIFF.

Up to 20 MiB and 4096 x 4096 pixels. One image at a time.

JPG and JPEG use the same format and replace transparency with white. ICO fits within 256 x 256 pixels. WebP output is lossless. GIF output is a static image. Animated GIF input is converted using its first frame. Only the first frame or icon is converted.
